# Case briefs

One brief per landmark case, in the format of [`templates/case-brief.md`](../templates/case-brief.md). Each lesson links to the cases it relies on, and each brief links back to the lessons that use it. Read the lesson first, then the brief, then do the "Test yourself" questions at the end of the brief.

Citations are given as reported. Where a brief was not certain of a citation or a Florida point, it says "(verify)". Check the primary source before relying on anything here.

## Reading order

The briefs are grouped by the module that uses them. If you are working through the course in order, you will meet them in roughly the order listed above. If you want a short tour of how American courts reason, read *Marbury*, *Erie*, *Meinhard*, *Lucy*, *Hadley*, *Jacob & Youngs*, and *Palsgraf* in that order.
