# mindnumb

Self-paced learning tracks.

| Track | What it is |
| --- | --- |
| [`learnlaw/`](learnlaw/README.md) | How law works, for a Florida business owner. Doctrines, landmark cases, how courts reason, and issue-spotting drills. US federal and Florida, LLC-centric. Education only. |
| [`games/precedent/`](games/precedent/index.html) | Precedent, a rule-inference game. A judge rules by a secret rule; read the rulings, file test cases, then predict five fresh rulings to pass the bar. Open the HTML file in a browser. |
