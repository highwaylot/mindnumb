# mindnumb

Self-paced learning tracks.

| Track | What it is |
| --- | --- |
| [`learnlaw/`](learnlaw/README.md) | How law works, for a Florida business owner. Doctrines, landmark cases, how courts reason, and issue-spotting drills. US federal and Florida, LLC-centric. Education only. |
| [`games/precedent/`](games/precedent/index.html) | Precedent, a rule-inference game set in a 3D tribunal. The Oracle rules by a secret rule; read the rulings on the galleries, file test cases, then predict five fresh rulings to pass the bar. Open `index.html` in a browser (needs WebGL and internet for the Three.js library); `classic.html` is the flat, dependency-free version. |
